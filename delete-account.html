로컬루트 계정 삭제 안내

로컬루트(구례 지역 여행 커뮤니티 앱) 회원 계정과 데이터를 삭제하는 방법입니다.

1. 앱에서 바로 삭제하기

  1. 로컬루트 앱에 로그인합니다.
  2. 내 정보 화면 아래의 회원 탈퇴를 누릅니다.
  3. 지워지는 기록을 확인하고 '탈퇴' 를 직접 입력한 뒤 탈퇴 버튼을 누릅니다.

탈퇴는 즉시 처리되며 되돌릴 수 없습니다.

2. 앱을 쓸 수 없을 때 요청하기

앱을 지웠거나 로그인할 수 없으면 아래 이메일로 요청해 주세요.

  • 받는 곳: zephyras@naver.com
  • 적을 것: 가입할 때 쓴 로그인 방식(구글·카카오·애플)과 닉네임

본인 확인 뒤 지체 없이 삭제하고 결과를 회신합니다.

3. 삭제되는 데이터

  • 계정 정보(로그인 식별자, 이메일, 닉네임, 프로필 이미지)
  • 내가 쓴 글·댓글·방명록(내 글에 달린 댓글 포함)
  • 여행 경로와 내가 만든 코스
  • 포인트와 포인트 내역
  • 캐릭터·꾸미기·경험치·업적
  • 영수증과 올린 사진
  • 방문 기록
  • 쪽지(보낸 쪽지와 대화)
  • 연령 확인·약관 동의 기록

4. 삭제 후에도 일정 기간 남는 데이터

  • 신고 처리 중인 쪽지 — 신고 처리와 다른 이용자 보호를 위해, 보낸 사람 계정과의 연결을 끊은 상태로 신고 처리 완료 후 30일까지(늦어도 신고일로부터 90일) 보관한 뒤 삭제합니다. 신고 처리 운영자만 볼 수 있습니다.
  • 다른 회원이 이미 구매한 코스 — 작성자 정보 없이 남습니다.
  • 법령상 보존 의무가 있는 정보는 그 기간 동안 보관합니다.

자세한 내용은 개인정보처리방침 §3을 참고해 주세요.
